# FitLog — Workout Library

A dark, no-nonsense gym companion built with Next.js. Browse 12 workouts, build your daily plan, save favorites for later, and track your progress — all with live stats and toast notifications.

---

## 🛠️ Technologies Used

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React Context API** (global state)
- **react-hot-toast** (notifications)
- **localStorage** (data persistence)

---

## ✨ 5 Key Features

1. **Workout Library** — Browse 12 workouts in a responsive grid with images, muscle tags, equipment, duration, calories, and rating.
2. **Today's Plan (Max 5)** — Add workouts to your daily plan with a 5-lift cap, duplicate protection, and toast feedback.
3. **Save for Later** — Bookmark workouts into a separate Saved tab that persists across page reloads.
4. **Live Metrics Dashboard** — Exercises / Minutes / Calories counters update automatically as you add or remove workouts.
5. **Mark as Done, Sort & Remove** — Mark workouts complete, remove them with a click, and sort the list by Duration, Calories, or Rating.
